작은 토큰 세트

색상, 반경, 간격, 그림자를 변수화해서 한 파일 안에서도 일관성을 유지했습니다.

기본 접근성

44px 타깃, 명확한 포커스 스타일, 반응형 브레이크포인트를 포함했습니다.

이걸로 충분한 이유

요구사항이 "아무 웹사이트 하나"인 만큼, 가장 작은 완결 단위로 결과를 남겼습니다. 이후 필요하면 이 파일을 기준으로 CSS 분리, 스크립트 추가, 프레임워크 이관을 이어갈 수 있습니다.

바로 열림 루트의 index.html 을 브라우저에서 열면 즉시 확인됩니다.
배포 친화적 정적 호스팅 환경이면 별도 설정 없이 올릴 수 있습니다.
확장 가능 콘텐츠와 스타일이 작게 정리돼 있어 다음 작업의 출발점으로 쓰기 쉽습니다.
